# ПДД Академия · 0.1.0

Нативное Android-приложение на Kotlin и Jetpack Compose для изучения российских билетов категории A/B. Все вопросы и иллюстрации включены: для занятий не нужны сервер, аккаунт и интернет.

## Открыть и запустить

1. Распакуйте архив, откройте папку `PddAcademy` в Android Studio через **Open**.
2. Выберите Gradle JDK 17. Установите Android SDK Platform 35 и Build Tools 35.0.0.
3. Дождитесь Gradle Sync и нажмите Run на устройстве или эмуляторе с Android 8.0+.

Связка: AGP 8.9.2, Gradle 8.11.1, Kotlin 2.1.20, Compose BOM 2025.04.01, compile/target SDK 35, min SDK 26. `local.properties` создаётся Android Studio для вашего компьютера.

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Приложенный APK — отладочная сборка для тестирования. Для публикации создайте собственный ключ подписи; ключей и секретов в исходниках нет.

## Возможности

- Знакомство с приложением и цель 10/20/40 вопросов в день.
- Главная: план на день, прогресс, серия дней, продолжение занятия.
- 40 билетов и 800 вопросов A/B; темы; поиск вопросов и тем.
- Объяснения ответов, избранное, увеличение картинок жестами и кнопкой.
- Экзамен: четыре случайных блока по пять вопросов, 20 минут основного этапа.
- Подтверждение ответа отдельной кнопкой; повторное нажатие не засчитывается повторно.
- Одна ошибка — пять дополнительных вопросов за пять минут. Две в разных группах — десять за десять минут. Третья ошибка, две в одном блоке или ошибка в дополнительном этапе завершают экзамен.
- Пропущенные по окончании времени вопросы учитываются как ошибки. Дополнительный этап получает отдельное время без переноса остатка основного.
- Свободный выбор порядка ответов текущего этапа. На экзамене объяснения открываются только после завершения.
- Быстрая тренировка, ошибки, интервальное повторение, избранное, марафон.
- Вопрос выучен после двух верных ответов подряд. Интервалы повторения: 1, 3, 7, 14, 30 дней.
- Статистика, активность за семь дней, слабые темы, история 100 занятий (15 последних отображаются в интерфейсе).
- Справочник 310 знаков с поиском и описаниями.
- Светлая, тёмная и системная темы; системные отступы; прокрутка длинного содержимого.
- DataStore сохраняет прогресс и занятие после каждого изменения. Перезапуск восстанавливает занятие. Таймер работает при сворачивании.
- Рекламы, аналитики и регистрации нет.

## Архитектура

`domain/Models.kt` — сериализуемые модели. `domain/StudyEngine.kt` — чистая Kotlin-логика экзамена и повторений. `data/StudyRepository.kt` — офлайн-контент и DataStore. `StudyViewModel.kt` — последовательные изменения через Mutex и StateFlow. `ui/` — экраны и компоненты Material 3. `scripts/` — импорт и валидация контента. `src/test/` — 20 тестов логики и 5 тестов интерфейса/сохранения.

Прогресс, активное занятие и история записываются одним состоянием. В пределах одной загрузки устройства таймер использует монотонное время, после перезагрузки — сохранённый календарный срок. История ограничена, чтобы хранилище не росло бесконечно.

## Данные и ограничения

Источник: [etspring/pdd_russia](https://github.com/etspring/pdd_russia), снимок `fa37933b2ea686db47c64401773e53f6775b8df0`, импорт 07.09.2026. Исходное описание сохранено в `docs/SOURCE_README.md`; контрольная сумма — в `assets/content_manifest.json`.

800 вопросов содержат 541 уникальную иллюстрацию. Из 310 знаков у 22 отсутствуют изображения в исходном репозитории. Эти карточки сохраняют текст и явно показывают отсутствие картинки; похожими знаками они не подменены.

Дата импорта не подтверждает соответствие всех материалов актуальным ПДД. Перед публичным выпуском сверить вопросы, пояснения и знаки с официальной базой; проверить права на распространение стороннего контента. Отдельной лицензии на контент в корне источника нет. Приложение не связано с Госавтоинспекцией.

Экзаменационная логика ориентируется на пункты 123–139 приказа МВД от 20.02.2021 № 80: [официальная публикация](https://publication.pravo.gov.ru/document/0001202103230031), [текст](https://legalacts.ru/doc/prikaz-mvd-rossii-ot-20022021-n-80-ob-utverzhdenii/). Это учебная репетиция; она позволяет свернуть приложение при работающем таймере, в отличие от официального экзамена.

Нет облачной синхронизации, экспорта прогресса, push-напоминаний, отдельной книги с полным текстом ПДД, категории C/D и автоматического обновления базы. Удаление приложения удаляет прогресс. Резервное копирование ОС и перенос данных отключены.

## Обновление контента

```bash
python3 -m pip install Pillow CairoSVG
python3 scripts/import_questions.py /path/to/pdd_russia
python3 scripts/validate_assets.py
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

CairoSVG может потребовать системную библиотеку Cairo. В Android Studio Python не нужен: готовые данные уже включены. После изменения редакции необходимо спланировать миграцию прогресса: ID сейчас привязаны к номеру билета и вопроса.

## Реклама позже

Рекламный SDK отсутствует. Подключать его следует отдельно от `domain`; возможное место для блока — экран результата. Перед выпуском с рекламой добавьте настройки приватности и согласий для выбранного SDK и магазина. Не перекрывайте вопрос и активный экзамен.

Результаты проверки описаны в `VERIFICATION.md`. Тесты и сборка не гарантируют полного отсутствия дефектов; проверка на физических устройствах остаётся отдельным шагом.
